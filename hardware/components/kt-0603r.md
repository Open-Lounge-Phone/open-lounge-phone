# KT-0603R — red 0603 LED, status light (D2)

| | |
|---|---|
| MPN / maker | KT-0603R (0603, water clear), Hubei KENTO |
| Function here | the one status LED: IO44 → 1 kΩ → LED → GND (~1.3 mA) |
| Datasheet | https://datasheet.lcsc.com/datasheet/pdf/011ec3e8cb1e825f6961d29bc4db4c7a.pdf |
| LCSC / JLC | C2286; ~$0.008; **basic** |

Polarity: the drawing [p2] marks the cathode end green (its pad "2"; pad "1" = +). KiCad's
`LED_SMD:LED_0603_1608Metric` has pad 1 = K, so the marked end goes on pad 1 (the schematic
uses KiCad's numbering). IO44 is RXD0, an input during boot, so the LED stays dark until
firmware drives it.
