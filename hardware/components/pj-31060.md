# PJ-31060 — 3.5 mm TRRS handset jack (J2)

| | |
|---|---|
| MPN / maker | PJ-31060 (SMD, 6 terminals), HOOYA / Haoyu |
| Function here | handset port, CTIA: T = left, R1 = right (both the earpiece), R2 = GND, S = mic. TN (normally-closed contact on the tip spring) opens when a plug is in → JACK_DET (IO11 via 1 kΩ, internal pull-up; low with no plug because TN touches the tip and its 4.7 kΩ to GND). R1N unused. |

**UNVERIFIED:** the HOOYA drawing numbers the terminals 1-6, the KiCad footprint names them; the
pad geometry matches, but the mapping and the plug-axis height must be measured on a sample
(continuity with a plug in and out) before the M2 layout freezes. OMTP plugs (mic and ground
swapped) are not supported.
