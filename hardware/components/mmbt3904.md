| | |
|---|---|
| MPN / maker | MMBT3904 (SOT-23, marking 1AM), JSCJ |
| Function here | low-side switch for the piezo from IO8 through 1 kΩ (Ib ≈ 2.6 mA, Ic ≈ 5 mA) |

| Spec | Value | Source |
|---|---|---|

| VCEO / IC | 40 V / 200 mA | [p1] |
| hFE | 100-300 at 10 mA | [p1] |

IO8 is an ordinary GPIO (input at reset), so the ringer stays silent until firmware drives it.
