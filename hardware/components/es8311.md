# ES8311 — mono audio codec, DAC for speaker and AEC reference (U6)

> **H5 (2026-09-30, owner D14/D15):** the ES8311 is now the **only codec**: its **ADC records the handset mic** (MIC1P via 1 µF from the jack's mic line, MIC1N via 1 µF to the jack ground; PGA ≈ 18 dB; ASDOUT → 47 Ω → IO4) and its **DAC drives the earpiece** (OUTP → TS5A3166 → 2 × 22 µF → 22 Ω → T/R1) and the NS4150B. The ES8311 User Guide rev 1.11 p2 states the differential output "has a capability to drive 16 Ω or 32 Ω headphone load" (register 0x13 HPSW selects the HP drive), so no separate headphone driver is fitted (`sim/` b04: 98 dB SPL at full scale with an assumed 95 dB/mW receiver). No AEC reference any more (F-14 N/A). User Guide: https://files.waveshare.com/wiki/common/ES8311.user.Guide.pdf
