# TS5A3166 — earpiece switch, on only off-hook (U8)

| | |
|---|---|
| MPN / maker | TS5A3166DCKR (SC-70-5), Texas Instruments |
| Function here | Connects ES8311 OUTP (DC-biased at VMID ≈ 1.5 V) to the earpiece coupling capacitors. **IN = HOOK**: closed only while the Hall sensor reads off-hook, so the ringer never plays in the earpiece and the receiver is disconnected on hook, in hardware. A 22 kΩ bypass keeps the coupling caps charged (no pop when it closes; −52 dB leak while open, `sim/` b04). V+ = 3V3. |
| Requirements | HW-ELEC-26; HW-PRIV-03 |

## Why on the codec side of the capacitors

The switch passes only 0 … V+: on the jack side of the coupling capacitors the earpiece signal
swings below GND, so the switch sits between OUTP (VMID + signal, 0.86–2.14 V) and the caps.
