# 1N4148W — mic-line sense diode (D9)

| | |
|---|---|
| MPN / maker | 1N4148W (SOD-123), Semtech Electronics Ltd. (LCSC brand "ST") |
| Function here | One-way sense path from the handset mic line HS_MIC_F (anode) → 100 kΩ → MIC_SENSE (IO10, ADC1; 1 MΩ + 10 nF to GND). The ADC reads mic present (≈ 1.4–2.2 V), inline button pressed or an OMTP plug (≈ 0 V), and no plug (≈ 2.35 V) — only while the mic is powered. A GPIO driven high reverse-biases the diode, so firmware cannot bias (power) the capsule (HW-PRIV-03, `check_privacy`). |
| Requirements | HW-FUNC-18; HW-PRIV-03; HW-ELEC-23 |

## Notes

At 3.3 V reverse bias the leakage is orders of magnitude below 1 µA (b04: 0.3 nA with the model);
an electret JFET needs ≈ 0.1 mA to work.
