## Key numbers

| Quantity | Value | Source |
|---|---|---|
| Inductance (tool) | ≈ 4.8 µH (filament Neumann integral) | `gen_footprints.py` |
| Inductance (independent check) | ≈ 4.5 µH by the modified Wheeler formula for a square spiral (K1 = 2.34, K2 = 2.75; d_out ≈ 34 mm average side, d_in ≈ 23.2 mm, n = 9) — Mohan et al., "Simple accurate expressions for planar spiral inductances", IEEE JSSC 34(10), 1999 | calc |
| Resonance with 28.5 pF | 13.6 MHz (4.8 µH) … 14.1 MHz (4.5 µH) | f = 1/(2π√(LC)) |
| Target | 13.56 MHz (slightly above is usual to allow detuning by the phone) | ST25DV RF spec [ST25DV p1] |

The two estimates agree within ≈ 7 %; either places resonance within ≈ 4 % of 13.56 MHz with no
extra capacitor, so the DNP cap will likely stay small (≤ 3 pF) or unfitted. The 22 pF placeholder
value in the schematic would pull resonance to ≈ 10 MHz — keep it DNP until measured.
