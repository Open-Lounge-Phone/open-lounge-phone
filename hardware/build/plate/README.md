# Key plate outputs

MX cut-outs 14.0 mm at 19.05 mm pitch, e-ink pocket 79.4 x 37.1 mm, M2.5 clearance holes, light-pipe holes.

- `plate-gerbers.zip`, `gerbers/`: outline + silk
- `plate-outline.dxf`: outline for laser/CNC (mm)
