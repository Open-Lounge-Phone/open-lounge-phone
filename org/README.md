# GitHub organization files

`dot-github/` is the content of the **Open-Lounge-Phone/.github** repository: `profile/README.md`
is the organization page at https://github.com/Open-Lounge-Phone. Publish it by creating the
public `.github` repo in the org and copying this folder in. The `github:` entry in
`/.github/FUNDING.yml` and the site's sponsor link switch to the organization once it is
sponsorable.
